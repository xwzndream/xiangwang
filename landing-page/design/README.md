# 首页设计参考

此目录保存向往软件工作室首页的设计参考、实现截图和设计检查记录，供后续改版时对照使用。

## 文件说明

- `design-reference.png`：选定的首页视觉方案参考。
- `design-qa.md`：设计还原与检查记录。
- `design-qa-comparison.png`：参考方案与实现效果对比。
- `implementation-desktop.png`：桌面端首页实现截图。
- `implementation-mobile.png`：移动端首页实现截图。
- `implementation-desktop-viewport.png`：桌面端视口检查截图。
- `implementation-modal-viewport.png`：弹窗视口检查截图。
- `implementation-quote-viewport.png`：报价区域视口检查截图。

这些文件不参与网站运行和 Netlify 构建，仅作为后续设计与开发参考。
